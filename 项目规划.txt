一、目标
----------------------------------------------------------------
Edge TTS 的 Windows 桌面客户端：输入文字 -> 生成语音 -> 立即播放。
界面直角、简约、深浅双色主题跟随系统，强调色 #20808D（真绿松石）。
图标统一使用 assets/MaterialSymbolsSharp.ttf（Material Symbols Sharp）。

二、已确认的产品决策
----------------------------------------------------------------
1  历史卡片只在本次运行内有效：退出程序即清空缓存目录，必须点
   "下载"才能把 mp3 保存到磁盘（默认 音乐/ATTS/）。
2  播放：生成完成立即自动播放；同一时刻只播一条；切换卡片自动停前一条。
3  语速 / 音量各一个自绘旋钮（上下拖动），不提供音调 pitch。
4  保留 Windows 11 原生标题栏，只用 DWM 改标题栏颜色跟随主题，
   不改窗口圆角（保持系统默认行为）。
5  长文本：超过单段上限时按句子切成多段，逐段请求，
   每段各自落成独立的 mp3 片段，不做二进制拼接（不引入 ffmpeg）。
   一个请求 = 一个卡片 = 一组片段，播放时按顺序连续播，下载时保存全部片段。
6  强调色的"可调不透明度"指设计阶段使用不同 alpha 的强调色层级
   （Accent / AccentSoft / AccentFaint ...），不提供用户侧滑块。
7  不做托盘图标、不做最小化到托盘；应用单实例，重复启动会激活已有窗口。
8  产品名 ALambda TTS，署名 Anming_cat；界面语言中文。
9  打包：框架依赖单文件 publish + Inno Setup 安装包，
   安装时检测 .NET 10 桌面运行时，缺失则调用 install-dotnet 脚本自动下载安装。

四、界面
----------------------------------------------------------------
工具栏（高 52）：[音色按钮] ................. [语速旋钮] [音量旋钮] [设置]
  音色按钮显示 "图标 + 当前音色名 + 性别"，点击弹出面板：
  搜索框 / 性别筛选(全部/女声/男声) / 语言筛选 / 虚拟化列表，
  条目右侧显示自动获得的类别标签，选中即收起。

历史区（中部，占满剩余空间）：
  每张卡片 = 一次请求。左侧文本预览（最多 3 行），右侧播放/下载图标，
  底部强调色小字 "音色 · 语速 · 时长 · 片段数"；生成中显示细进度条。
  空状态显示居中的提示文字与图标。

输入区（下部）：
  多行文本框，焦点时整体高度 96 -> 168 平滑展开，失焦且为空时收回。
  支持粘贴、拖入 .txt（多文件按空行拼接）。右侧方形强调色发送按钮；
  生成中同一按钮变成取消（stop）。Enter 发送，Shift+Enter 换行，Esc 取消。

状态栏（底部 26）：左侧状态文字 + 进度百分比；右侧下载文件夹（点击打开）。

五、关键实现要点
----------------------------------------------------------------
* 旋钮用 OnRender 画 270 度弧 + 指针，垂直拖动 1 px = 1 个单位步长，
  滚轮步进 5，双击回默认值；值变化即时显示在右侧小字。
* 主题：所有颜色写入 Application.Resources（DynamicResource 引用），
  切换时整窗即时换肤；监听注册表 AppsUseLightTheme 跟随系统变化。
* 音色目录：启动时异步拉取，成功则写 %LOCALAPPDATA%\ALambdaTTS\voices.json；
  失败回退到本地缓存；语言显示名用 CultureInfo，特殊 locale 手工兜底。
* 合成：每段一个 Communicate，StreamAsync 流式写盘 -> 进度按
  "已完成段数 + 段内已播文本占比" 计算；支持 CancellationToken 取消。
* 音频：System.Windows.Media.MediaPlayer，MediaEnded 自动切下一片段。
* 缓存目录 %LOCALAPPDATA%\ALambdaTTS\cache，启动和退出各清理一次。

八、试用反馈修复（第二轮）
----------------------------------------------------------------
1  点音色没反应：根因是音色面板用了 Popup。Popup 是独立 HWND，命中测试与
   键盘焦点都不跟主窗口走（实测 Popup 里连 TextBox.Focus() 都返回 false）。
   改法：Popup 换成主窗口内的叠层 Grid（VoiceOverlay，遮罩 + 面板），
   遮罩点击收起、Esc 收起、开关按钮切换，面板打开后自动把光标放进搜索框。
   顺带把根 Grid 的工具栏行高写死 55，避免叠层把布局撑高。
2  点某个音色的判定不再依赖 ListBoxItem 的默认选中行为：改用
   ListBox.PreviewMouseUp + ContainerFromElement 自己命中容器再选中。
3  旋钮数字抖动：数值 TextBlock 固定 Width=42 + TextAlignment=Left。
4  语言筛选合并：VoiceEntry 增加 LanguageCode（locale 首段）与 75 条中文语言名，
   VoiceCatalog.Languages 按语言大类分组，下拉显示「中文（14）」；zh 排第一。
5  重复保存覆盖：TtsItem 记录 CreatedAt，下载文件名固定用它，
   File.Copy(overwrite: true)，状态栏提示「已覆盖 N 个文件」。
6  网络抖动体验：TtsService 失败重试由 2 次提到 3 次（间隔 400ms/800ms），
   底层异常翻译成人话（TLS 握手失败 / 网络连接失败 / 网络连接被中断），
   详细堆栈写 %LOCALAPPDATA%\ALambdaTTS\error.log；失败卡片加红色重试按钮，
   点一下用该卡片自己的文本与参数重来。
   起因：试用时遇到 IOException「Received an unexpected EOF or 0 bytes from
   the transport stream」，即 TLS 连接被中断，属于 TUN 代理抖动。
7  两套 harness：TtsProbe 44 项、UiHarness 61 项，全部通过。

十二、局域网互发朗读 / 去掉音量旋钮（第六轮，v1.1.0）
----------------------------------------------------------------
1  音量旋钮删除：工具栏只剩语速、语调两个旋钮，合成音量固定 100（Edge 侧 +0%）。
   AppSettings.Volume 字段保留（兼容老配置），不再从界面写入。
   腾出来的位置给局域网按钮，窗口宽度不必再改。
2  协议（Services/Lan）：
   - LanCodec：4 字节长度前缀 + UTF-8 JSON，TCP 双向帧；UDP 发现报文同一套字段。
   - LanService：TcpListener 常驻监听 + Accept 握手 + 读循环 + 心跳 + UDP 应答。
     握手 hello -> pair(配对码) -> pair-ok / pair-failed；成功后这条 TCP 就是消息通道。
     心跳 5 秒 ping、20 秒没 pong 判死；读到 EOF 或 bye 都算断开。
     广播目标 = 255.255.255.255 + 每块网卡的定向广播（Radmin 虚拟网卡靠后者）。
     广播不通时还有「直接连接」手动填 IP，两条路都留。
3  界面：工具栏新增局域网按钮（图标右上角小圆点表示已连接）；
   面板沿用语色面板那套窗口内叠层（LanPanelView：开关 / 本机名 / 配对码 /
   发现列表 / 直接连接 / 断开 / 状态行）。Esc、点遮罩、再点按钮都能收起。
   设置持久化：LanEnabled / LanDeviceName / LanPort / LanPairCode /
   LanPeerName / LanPeerHost / LanPeerPort，配对码首次打开面板时随机生成。
4  收发流程：
   - 本机发送：StartSynthesisAsync 里先建卡片（连着局域网时标「由 本机名 发送」），
     再把文本连同音色 / 语速 / 语调 / 音量发给对端，然后照常本地合成播放。
   - 对端接收：MessageReceived 回到界面线程入队，PumpRemoteQueueAsync 串行处理
     （本机正在合成时等它结束），每条形如「来自 电脑 A」的卡片 + 立即合成 + 自动播放；
     音色优先用发送方的，找不到就退回本机当前音色。
   - 断线重连：DispatcherTimer 每 5 秒检查，未连上且记录过对端地址就悄悄重连。
5  自检：
   - TtsProbe 66 项：新增 18 项覆盖配对成功 / 配对码拒绝 / 收发消息（正文、来源、
     音色语调参数）/ 广播应答 / 主动断开与对端感知 / 停止后状态。
   - UiHarness 109 项：新增音量旋钮已移除、局域网按钮与面板、开关写入设置并开始监听、
     真起一个 LanService 连进窗口走完整 TCP（对端→本机合成播放、
     本机→对端收到正文）、断开感知、远端消息排队合成播放。

十五、对方消息不该替我出声（第九轮，v1.1.3）
----------------------------------------------------------------
1  问题：对端发来的消息是把发送方的音量写进卡片去合成的，
   所以本机音量拧到 0 也照样响——用户反馈"别人发来还是有声音"。
2  改法一：远端消息一律用本机音量旋钮的值做 volume，
   发送方的 Volume 字段仍然传，但只作参考，接收端不采用。
3  改法二：面板新增「静音对方」开关（AppSettings.LanMuteIncoming）：
   打开后收到的消息照样合成出卡片，但不自动播放（状态栏提示"静音模式没有播放"），
   想听点卡片上的播放键。
   为此 RunSynthesisAsync 加了 autoPlay 参数，默认 true。
4  自检：TtsProbe 66 项、UiHarness 131 项全部通过。
   新增：静音开关写进设置、静音时照样生成卡片、静音时不播放、
        远端消息用本机音量（对方 100 本机 70 → 卡片 70）、
        关掉静音后会播放。

十六、音量改成全局播放音量（第十轮，v1.1.4）
----------------------------------------------------------------
1  需求：音量只控制本软件，别塞进消息里发给对方。
2  改法：
   - AudioPlayer 增加 Volume（0~1），直接写 MediaPlayer.Volume，
     拖动旋钮对正在播放的片段立刻生效（不用重新合成）。
   - 合成请求的音量固定 100：Edge 侧永远是原始音量，
     所以下载保存的 mp3 不再被压低，也没有"某条卡片音量焊死"的问题。
   - TtsItem 不再有 Volume 字段，卡片小字不再显示音量。
   - 局域网帧与 LanChatMessage 删掉 Volume：只传文本 / 音色 / 语速 / 语调。
     旧版本对端发来的多余字段会被 JSON 忽略；反过来旧版本收不到音量字段
     会按 0 处理，所以两端都要升到 1.1.4。
   - Knob 增加 ValueChanged 事件（滚轮 / 拖拽 / 双击 / 代码赋值都会触发），
     主窗口据此同步播放器音量；设置里仍然保存音量，下次打开继续用。
3  自检：TtsProbe 67 项（新增"消息里不再携带音量字段"）、
   UiHarness 128 项全部通过。
   新增：音量旋钮控制播放器全局音量（70 → 0.7，拉满 → 1.0）、
        卡片小字不再写音量、远端消息也走全局音量。
